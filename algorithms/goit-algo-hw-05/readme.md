# goit-algo-hw-05

## Порівняння алгоритмів пошуку підрядка

У роботі реалізовано та протестовано три алгоритми пошуку підрядка:

- Боєра-Мура
- Кнута-Морріса-Пратта
- Рабіна-Карпа

Для вимірювання продуктивності використано модуль `timeit`. Кожен алгоритм перевірявся на двох текстових файлах для:

1. підрядка, який є у тексті;
2. вигаданого підрядка, якого у тексті немає.

## Результати

Після запуску `main.py` програма виводить середній час одного пошуку в мілісекундах для кожного алгоритму.

### Стаття 1: Використання алгоритмів у бібліотеках мов програмування

| Алгоритм             | Існуючий, мс | Вигаданий, мс |
|----------------------|--------------|---------------|
| Боєра-Мура           | 0.063530     | 0.210057      |
| Кнута-Морріса-Пратта | 0.292679     | 1.704526      |
| Рабіна-Карпа         | 0.493687     | 4.264542      |

Найшвидший для наявного підрядка: Боєра-Мура

Найшвидший для вигаданого підрядка: Боєра-Мура

### Стаття 2: Методи та структури даних для рекомендаційної системи

| Алгоритм             | Існуючий, мс | Вигаданий, мс |
|----------------------|--------------|---------------|
| Боєра-Мура           | 0.008265     | 0.442686      |
| Кнута-Морріса-Пратта | 0.024632     | 3.925069      |
| Рабіна-Карпа         | 0.023208     | 6.732081      |

Найшвидший для наявного підрядка: Боєра-Мура

Найшвидший для вигаданого підрядка: Боєра-Мура

Алгоритм Боєра-Мура показав найшвидший час пошуку для обох статей та для обох типів підрядків. Алгоритм
Кнута-Морріса-Пратта показав стабільні результати, але поступався Боєру-Муру. Алгоритм Рабіна-Карпа виявився
найповільнішим серед трьох, особливо для вигаданого підрядка. 

## Висновки

За результатами вимірювань потрібно визначити найшвидший алгоритм окремо для кожної статті та загалом.

Зазвичай алгоритм Боєра-Мура демонструє високу швидкодію для пошуку у великих текстах, оскільки може пропускати кілька
символів після невідповідності. Алгоритм Кнута-Морріса-Пратта має гарантовану часову складність `O(n + m)` і не
повертається до вже переглянутих символів тексту. Алгоритм Рабіна-Карпа зручний для пошуку кількох шаблонів, проте в
окремих випадках може поступатися іншим алгоритмам через обчислення хешів.
