## Завдання 1. Алгоритми видачі решти

Реалізовано два алгоритми для формування суми монетами номіналів:

```python
[50, 25, 10, 5, 2, 1]
```

### Жадібний алгоритм

Функція `find_coins_greedy(amount)` вибирає найбільший доступний номінал монети, доки не буде сформована вся сума.

Приклад для суми `113`:

```python
{50: 2, 10: 1, 2: 1, 1: 1}
```

Часова складність жадібного алгоритму:

$$O (k)$$

де `k` — кількість номіналів монет. У цьому завданні кількість номіналів є сталою, тому алгоритм працює дуже швидко
навіть для великих сум.

### Алгоритм динамічного програмування

Функція `find_min_coins(amount)` знаходить комбінацію монет з мінімальною загальною кількістю монет.

Приклад для суми `113`:

```python
{1: 1, 2: 1, 10: 1, 50: 2}
```

Часова складність алгоритму динамічного програмування:

$$O (amount \cdot k)$$

Просторова складність:

$$O (amount)$$

### Висновки

Для заданого набору монет `[50, 25, 10, 5, 2, 1]` жадібний алгоритм формує оптимальну кількість монет і працює значно
швидше за алгоритм динамічного програмування.

Жадібний алгоритм є ефективнішим для великих сум, оскільки його швидкодія майже не залежить від значення суми. Алгоритм
динамічного програмування обчислює оптимальний результат для кожної проміжної суми, тому зі збільшенням суми потребує
більше часу та пам'яті.

Водночас динамічне програмування є універсальнішим. Для довільних наборів номіналів жадібний підхід не завжди гарантує
мінімальну кількість монет, тоді як алгоритм динамічного програмування гарантує оптимальний результат.

## Завдання 2. Метод Монте-Карло

Обчислено визначений інтеграл функції:

$$f (x) = x^2$$

на проміжку від `0` до `2`.

Аналітичне значення інтеграла:

$$\int_0^2 x^2 dx = \left.\frac{x^3}{3}\right|_0^2 = \frac{8}{3} \approx 2.666667$$

Метод Монте-Карло випадково генерує точки у прямокутнику розміром:

- ширина: `b - a = 2`;
- висота: `max(f(x)) = 4`;
- площа прямокутника: `8`.

Площа під графіком оцінюється як частка точок, що потрапила під криву, помножена на площу прямокутника.

Для перевірки результату використано функцію `scipy.integrate.quad`.

### Висновки

Результат методу Монте-Карло є наближеним і близьким до аналітичного значення та результату `quad`.

Похибка залежить від кількості випадкових точок: що більше значення `samples`, то точніше наближення. Метод Монте-Карло
корисний для задач, де аналітичне інтегрування складне або неможливе, хоча для простих функцій метод `quad` надає
точніший результат.
