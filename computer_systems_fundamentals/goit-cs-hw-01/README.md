# Завдання 1: Обчислення арифметичного виразу (Assembly)

Цей репозиторій містить програму мовою асемблера (`task1.asm`), яка обчислює арифметичний вираз `b - c + a` і виводить
результат на екран у середовищі DOSBox.

Для максимальної простоти запуску на Windows та інших ОС без встановлення DOSBox чи X-сервера, використовується Docker.
**Компіляція програми (NASM) відбувається автоматично під час збірки образу**, а результат виводиться прямо у ваш
веббраузер (через noVNC).

## Вимоги

- Встановлений [Docker](https://www.docker.com/) (Docker Desktop для Windows/Mac або Docker Engine для Linux).
- Файли `Dockerfile` та `task1.asm` повинні знаходитися в одній теці.

## Інструкція із запуску (Windows / PowerShell / Linux / Mac)

Відкрийте термінал (або PowerShell) у теці, де знаходяться ваші файли, та виконайте наступні два кроки:

### 1. Збірка Docker-образу (та автоматична компіляція)

Під час виконання цієї команди Docker скопіює ваш код і самостійно скомпілює його у файл `task1.com`.

```powershell
docker build -t web-dosbox .
```

*(Якщо ви зміните код у файлі `task1.asm`, вам потрібно буде виконати цю команду ще раз, щоб оновити програму).*

### 2. Запуск програми у DOSBox

Запустіть готовий контейнер, відкривши порт 8080 для вебінтерфейсу:

```powershell
docker run --rm -it -p 8080:8080 web-dosbox
```

### 3. Перегляд результату

1. Відкрийте ваш веббраузер (Chrome, Edge, Firefox тощо).
2. Перейдіть за адресою: **[http://localhost:8080/vnc.html](http://localhost:8080/vnc.html)**
3. Натисніть кнопку **"Connect"** (пароль не потрібен).
4. Ви побачите вікно DOSBox із виведеним результатом (наприклад, `Result: 6`).
5. Зробіть скриншот цього вікна для здачі завдання.

### Зупинка

Щоб зупинити роботу DOSBox і закрити контейнер, поверніться у термінал, де ви його запустили, та натисніть `Ctrl+C`.
